# App Icon

Place a 1024x1024px PNG file named `Icon-1024.png` in this directory.

For now, the app will build without an icon (showing default blank icon).

You can generate the icon using:
- Figma/Sketch
- Online icon generators
- Or any image editing tool

Recommended: Create a gradient from #667EEA to #764BA2 with a white "C" logo.
